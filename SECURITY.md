# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public Issue. Contact the repository owner privately through the email address listed on the GitHub profile and include the affected component, reproduction conditions, and potential impact. Do not include real credentials, unpublished research materials, or personal data.

## Scope

This repository is a sanitized portfolio snapshot. Production credentials, data, Cloudflare resource identifiers, and operational configuration are intentionally excluded. The public source should not be treated as a ready-to-deploy production service without an independent security review and environment-specific hardening.
